# Social Media Performance Dashboard (July–September 2026)

This repository contains a standalone Arabic social media performance dashboard for:
- ذاكر من المعاصر
- ذاكر من الامتحان

## View the dashboard locally
Open `index.html` in a modern browser. An internet connection is required to load the Google Cairo font and Chart.js from their CDNs.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` (and this `README.md`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The dashboard URL will appear in the Pages settings.

## Notes
- `index.html` is the website entry point expected by GitHub Pages.
- Dashboard data and visualizations are embedded in the HTML file.
- Chart.js and the Cairo font are loaded from external CDNs, so those resources require internet access.
